# Ranked.

**Ranked.** is my project for the optional **HTML and CSS Redesign Midterm Assignment** of the *Introduction to Web Applications* course.

The assignment consisted of redesigning the social network/blog-style application developed during the lab sessions using **HTML, CSS, Bootstrap, semantic markup, and responsive design**.

For my proposal, I transformed the original application into **Ranked.**, a fictional social platform focused on workplace transparency and company reviews. Users can visually share work experiences, salaries, pros and cons, reactions, comments, and company trends.

## Main Changes

The redesign introduces:

* a completely new visual identity and branding;
* redesigned navigation and social feed;
* company review cards with salary, pros and cons;
* trending company sections;
* dedicated post and profile pages;
* a fictional **Ranked. PRO** subscription page;
* responsive layouts for desktop and mobile;
* extensive Bootstrap customization with custom CSS.

## Pages

The project consists of the four pages required by the assignment:

* `home.html` — main social feed;
* `post.html` — individual post page;
* `profile.html` — user profile;
* `pro.html` — fictional premium subscription page.

### Note about `index.html`

`index.html` is **not part of the actual redesign**.

Its only purpose is to allow **Nginx running on my personal self-hosted homelab** to correctly route requests from the website root to `home.html`.

## Technologies

* HTML5
* CSS3
* Bootstrap 5
* Bootstrap Icons
* Font Awesome
* Google Fonts

The project is entirely frontend-based, as no backend implementation was required for the assignment.

## Responsive Design

The interface was designed to remain usable and visually coherent across different screen sizes, with particular attention to smartphone layouts.

Bootstrap responsive utilities and custom CSS are used to adapt navigation, cards, spacing, and page structure between desktop and mobile devices.
